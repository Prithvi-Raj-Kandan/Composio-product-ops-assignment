# Where the agent stops and a human decides

The agent answers `unknown` rather than guessing, and no hand-edited cell is ever presented as agent output. On each run, the workflow hands off to a human at the points below. Counts are from this run (pass 3 data). The page computes them live from `data/`.

| Handoff | Trigger (in the code) | Human decides | Edits | Flows back via | This run |
|---|---|---|---|---|---|
| Which company is this? | The agent only accepts pages on hosts derived from the task's hint (`url_is_official` in `seed.py`). There is no automatic confidence score. When the hint is ambiguous (a rebrand, a generic name, or a hinted host with no API docs), the row comes back mostly `unknown`. | The official homepage and docs URL | `data/domain_overrides.csv` (app, homepage, docs_url, extra_source, note) | Rerun the app (`research-one`, or `run --pass 1 --only APP`). The record gets `provenance.source = human_override`. | 6 overrides (iPayX, fanbasis → Commas, Paygent Connect, Waterfall.io, higgsfield, YouTube Transcript) |
| Verification loops could not settle a field | In pass 2 a field is still *contradicted* or *insufficient* after `MAX_LOOPS = 2` re-research loops (`graph.py`), so `needs_human = true` with the reason "verification loops exhausted: FIELDS". Rows whose pass 2 crashed also stay `needs_human`. | Whether a quoted page settles the field, or it stays `unknown` | Reads `needs_human_reasons` in `data/results.json` and the findings in `data/runs/APP_pass2.json`. A better source goes into `domain_overrides.csv` (extra_source). | Delete the app's checkpoint in `cache/checkpoints/`, then `run --pass 2 --resume` or `pass3 --resume` | 47 needs_human rows: 10 loops exhausted, 37 pass-2 crash rows |
| The verifier contradicted a claim | The second model or the MCP registry returned *contradicted*. Only this verdict demotes a claim to `unknown`, and it is stored per field in `verifier_verdicts`. | Who is right: the quoted doc or the verifier | The app's run log in `data/runs/`. The fixed rule (`derive_verdict`) then sets buildability to no or yes_with_caveats. | Whether the gate is real for Composio (partner program, sales call, a trial that needs a card) | Nothing in the data. ## One-time setup (not part of each run)

Set `COMPOSIO_API_KEY`, `GEMINI_API_KEY`, `GROQ_API_KEY` and `TAVILY_API_KEY` in the shell, or as repository secrets for the GitHub Action. Run `python -m opsresearch connect-tavily` once. Search results are cached in `cache/_search/`, so reruns are free. Approve merges and the GitHub Pages publish; the agent does not publish on its own.

## The gold set is not a replicator's job

`data/gold/gold_sample.csv` is the frozen 20-app stratified sample (seed `20261123`): two apps per category, one dev and one test, with archetype tags. The labels were drafted by an AI model from official docs, independently of this pipeline, and human review is pending. `eval` reports null accuracy for unlabelled cells; it never invents a score.
